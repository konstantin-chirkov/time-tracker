# Time Tracker

Трекер времени для почасовой оплаты — таймер и история полностью связаны. Есть как веб-версия (один HTML-файл), так и нативное macOS-приложение (`.dmg`, собрано через Tauri).

## Установка (macOS)

Универсальная сборка — работает и на Apple Silicon (M1/M2/M3/M4), и на Intel Mac.

1. Открыть **`Time Tracker.dmg`** в корне этой папки.
2. Перетащить «Time Tracker» в «Applications».
3. При первом запуске macOS покажет предупреждение «неизвестный разработчик» (приложение не подписано платным Apple Developer аккаунтом — это ожидаемо для личного инструмента). Чтобы разрешить: **правый клик по иконке → «Открыть» → «Открыть»** в диалоге. Дальше запускается как обычно, двойным кликом.

## Запуск веб-версии (без установки)

Открыть `dist/index.html` в браузере. Для корректной загрузки шрифта — через локальный сервер:

```bash
cd "Projects/time-tracker/dist"
python3 -m http.server 8080
```

и зайти на `http://localhost:8080`.

## Что уже работает

### Таймер
- Дефолтное состояние — только кнопка «Начать запись», без рамки карточки.
- Пуск / пауза / сброс (с подтверждением, сколько времени пропадёт).
- Тег/проект — комбобокс с поиском и созданием тега на лету.
- Ставка в рублях, подставляется автоматически по последнему значению для выбранного тега.
- «Сохранить» создаёт настоящую запись (реальное время начала/окончания по системным часам, сумма = ставка × длительность) и сразу кладёт её в историю — таймер и история полностью связаны.

### История
- Календарь с полноценной навигацией по месяцам и годам (не заглушка — считает дни недели, «сегодня», подсветку выбранного дня для любого месяца).
- Период: пресеты (Сегодня / Эта неделя / Этот месяц / Прошлый месяц / Последние 30 дней) считаются от реальной даты, плюс «Свой период» — календарь с выбором диапазона, включая диапазоны через границу месяца.
- Поиск по названию задачи — ищет по всем реальным записям.
- Фильтр по тегам — мультивыбор с поиском/созданием тега, влияет на виджеты статистики (часы/заработано/задачи).
- Виджеты статистики считаются живьём по выбранному периоду и фильтру тегов.
- Панель дня: список записей, добавление задним числом на любую дату, редактирование любого поля записи (название, дата, время, тег, ставка) прямо в списке, удаление с подтверждением.
- Пустые состояния — честные, без выдуманных данных.

### Данные
- Сохраняются в localStorage — записи, теги и ставки переживают перезапуск приложения.
- **Одно устройство, без облака.** Ничего никуда не отправляется.

### Дизайн
- Токены (цвета, радиусы, отступы, типографика) взяты из shadcn/ui-кита пользователя в Figma — см. `../design-system/shadcn-figma-kit.md`.
- Светлая и тёмная тема (подхватывает системную).
- Адаптивно от 375px (мобильный) до широкого десктопа; нативное окно стартует на 820×640, растягивается свободно.
- Шрифт Inter (Google Fonts — в нативном приложении при отсутствии интернета подставится системный шрифт).
- Иконка — тёмный квадрат со скруглёнными углами и буквой «Т».

## Чего пока нет (сознательно)

- **Нет мультипользовательского режима / синка между устройствами** — осознанно отложено, при необходимости предполагался local-first подход с Supabase (авторизация + Postgres) поверх уже готового локального UI.
- **Windows-сборка не собрана** — конфигурация Tauri это поддерживает, но сборка под Windows делается на Windows-машине (или через CI), здесь не запускалась.
- Макеты не перенесены в сам Figma-файл пользователя — на момент работы MCP-коннектор Figma был не авторизован в сессии.
- Приложение не подписано и не нотаризовано Apple (требует платный Apple Developer аккаунт) — отсюда предупреждение Gatekeeper при первом запуске.

## Пересборка после изменений в dist/index.html

Универсальная сборка (Apple Silicon + Intel одним файлом):

```bash
source "$HOME/.cargo/env"
cd "Projects/time-tracker/src-tauri"
rustup target add x86_64-apple-darwin   # один раз
cargo tauri build --target universal-apple-darwin
```

Готовые `.app` и `.dmg` появятся в `src-tauri/target/universal-apple-darwin/release/bundle/`.

Если сборщик .dmg падает на шаге `bundle_dmg.sh` (известный баг create-dmg с AppleScript/Finder в некоторых средах) — `.app` при этом уже собран успешно, `.dmg` можно упаковать вручную:

```bash
STAGE=$(mktemp -d)
cp -R "src-tauri/target/universal-apple-darwin/release/bundle/macos/Time Tracker.app" "$STAGE/"
ln -s /Applications "$STAGE/Applications"
hdiutil create -volname "Time Tracker" -srcfolder "$STAGE" -ov -format UDZO "Time Tracker.dmg"
```

Сборка только под текущий чип (быстрее, но без переносимости):

```bash
cargo tauri build
```

Появится в `src-tauri/target/release/bundle/`.
