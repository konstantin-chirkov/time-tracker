# Time Tracker

*[Read in English](README.md)*

Приложение MacOS и Windows для учёта рабочего времени при почасовой оплате. Позволяет фиксировать время в моменте, вести историю по задачам, видеть заработок за любой период и выставлять клиентам счета в PDF — без подписок, прямо у себя на компьютере.

| ![Таймер](screenshots/timer.png) | ![История](screenshots/history.png) |
|---|---|

Скачать готовые установщики: **[Releases → Time Tracker v0.1.0](https://github.com/konstantin-chirkov/time-tracker/releases/latest)**

## Возможности

- Учёт времени — запуск, пауза и остановка таймера в один клик. Хоткеи для более быстрой работы.
- Теги и ставки — организуйте задачи по тегам и задайте ставку и валюту для каждого.
- История — просматривайте работу в календаре, ищите задачи, фильтруйте по тегам и редактируйте прошлые записи.
- Счета — генерируйте PDF-счета по любому проекту или периоду, добавляйте подпись и ведите историю счетов.

## Веб-версия (самый простой способ)

Ничего не устанавливать вообще:

1. Скачать **`Time Tracker.html`**.
2. Открыть файл двойным кликом — откроется в браузере по умолчанию.
3. Всё работает как в обычном приложении, данные сохраняются в самом браузере (localStorage) на этом устройстве.

Никаких предупреждений системы безопасности — это просто файл, не исполняемая программа. Минус один: если очистить данные браузера, история пропадёт (в отличие от .dmg/.exe, где данные не зависят от браузера).

Если вместо этого нужно полноценное приложение на компьютере — ниже установщики под конкретную систему.

## Установка на Mac

Работает и на новых Mac (M1/M2/M3/M4), и на старых Intel.

1. Скачать и открыть **`Time Tracker.dmg`**.
2. Перетащить «Time Tracker» в папку «Applications».
3. При первом запуске macOS заблокирует приложение как загруженное от неустановленного разработчика (это нормально — приложение не покупало платную подпись Apple):
   - Нажать **«ОК»** в предупреждении.

     <img src="screenshots/mac-install-1-blocked.png" width="360">

   - Зайти в **Системные настройки → Конфиденциальность и безопасность**, прокрутить до раздела «Безопасность» и нажать **«Подтвердить вход»** рядом с Time Tracker.

     <img src="screenshots/mac-install-2-settings.png" width="500">

   - Открыть приложение ещё раз — появится второй диалог с подтверждением. Нажать **«Открыть»**.

     <img src="screenshots/mac-install-3-confirm.png" width="360">
4. Дальше приложение открывается обычным двойным кликом.

## Установка на Windows

1. Скачать и запустить **`Time Tracker.exe`**.
2. Windows покажет предупреждение SmartScreen «Windows защитила ваш компьютер» (по той же причине — без платной подписи). Нажать **«Подробнее»** → **«Выполнить в любом случае»**.
3. Пройти мастер установки (Next → Next → Install).
