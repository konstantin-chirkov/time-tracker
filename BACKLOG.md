# Backlog

Не срочные, но подтверждённые баги/улучшения. Не реализовывать без явного запроса.

## 1. Добавить время при старте таймера

При запущенном таймере (в начале) хочется сразу приплюсовать ко времени ещё полчаса или час. Быстрый выбор +30 мин / +1 ч, плюс произвольное значение (по выбору времени не ограничиваем).

Юзкейс: запустил таймер и начал задачу, а перед этим около получаса общался в Telegram и хочет засчитать это время, не заходя в редактирование записи. По сути событие просто начинается раньше.

## 2. Кастомные шаблоны счетов

Возможность загрузить свой шаблон счёта (у автора он уже шаблонизирован). В шаблоне можно прямоугольниками выделять, где и какая сущность живёт и какие поля нужно добавить; от этой разметки перестраиваются поля формы счёта.

Сущность «шаблон счёта» должна начать жить в разделе счетов: выбирается для разных проектов или вообще без проекта, чтобы можно было выбрать разное. При выставлении счёта шаблон выбирается по названию, которое ввёл пользователь, и запоминается под каждый проект.

## 3. Запоминание выбора по проекту — по всему продукту

Выбор (шаблон счёта и аналогичные) запоминается отдельно под каждый проект. Если проекта нет, прошлый выбор запоминать не надо: выпадайка остаётся пустой, подтягивается только то, что относится к проекту. Сейчас такого запоминания не хватает во всём продукте.

## 4. Работа по API (нужен ресёрч)

Нужно исследовать, что вообще можно и стоит делать через API, и реализуемо ли это в нашем формате (один html + Tauri, без бэкенда). Пока это ресёрч, а не готовая задача.

Вопросы для ресёрча:
- Какой именно API нужен: внешние сервисы (интеграции, экспорт/синхронизация записей и счетов) или собственный API у приложения.
- Что реально возможно без своего сервера: данные лежат в localStorage на устройстве, а запросы из браузера упираются в CORS и хранение ключей.
- Что нужно для авторизации и безопасного хранения токенов в веб-версии и в нативных приложениях.
